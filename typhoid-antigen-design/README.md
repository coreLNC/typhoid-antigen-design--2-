# Typhoid and paratyphoid diagnostic antigen design (in silico)

Integrated comparative genomic and immunoinformatic analysis of three candidate serodiagnostic antigens
of *Salmonella* Typhi and Paratyphi A, **HlyE**, **CdtB** and **YncE**, with the aim of finding antigenic
regions that are conserved in typhoidal *Salmonella* but divergent from non-typhoidal *Salmonella* (NTS)
and other relevant bacteria, as a more specific basis than the Widal test (Nigeria focus).

**Status:** fully computational. Nothing here has been tested with patient sera. Sequence specificity is not
antibody specificity, and gene presence is not expression.

Author: David Ayobami Okeleye (MSc Public Health Biotechnology, University of Ibadan;ImmunoInformatics:Diagnostic Antigen Design-CompChemHub)

## Main results

- **Epitope sequence does not separate Typhi from NTS.** The minimum mismatch between each Typhi 9-mer and
  any NTS sequence is 0 in every window of HlyE (295 windows), CdtB (261) and YncE (345). Specificity against NTS
  comes from gene absence: hlyE in 7.6% (10/131) and cdtB in 8.4% (11/131) of NTS genomes, yncE in all.
- **HlyE and CdtB are co-carried** by the same 10 NTS genomes (Enteritidis, Indiana, Schwarzengrund, Nima and a
  subsp. *diarizonae* genome), and by 9 of 18 West African non-Typhi genomes, so a HlyE+CdtB panel gains no NTS specificity.
- **The 5 Enteritidis HlyE copies are identical to Typhi over all 303 residues**; no substitution is shared by all NTS carriers.
- **22 ranked segments:** 20 pan-typhoidal and 2 Typhi-selective (CdtB 221-230, G228S; HlyE 202-213, N213D),
  each differing from Paratyphi A by one residue. These are candidates for experimental testing, not discriminators.
- **Nigerian Typhi (140 assemblies):** HlyE and CdtB identical to the reference in all genomes in which they were detected
  (137 and 138); YncE K335R in 12 of 138.
- Primary ranking (no prior-evidence term): CdtB segments 1-9, HlyE 102-111 tenth. The prior-weighted ranking
  (sensitivity analysis) puts HlyE 48-60 first. See `results/epitopes/ranking_summary_v3.csv`.

## Repository layout

```
data/input/          genome labels, antigen sequences (full length and mature), protein-level prior evidence, proteome list
results/genomes/     presence/absence table, alignments (HlyE, CdtB), sliding 9-mer window tables, gene prevalence
results/epitopes/    consensus epitopes, per-residue tool calls, ranking (v3), classes, pore accessibility, DIAMOND summary
results/west_africa/ tblastn hits, SISTR serovar calls, West African genome list (NCBI metadata)
structures/          1QOY, AlphaFold models (AF-Q8Z740-F1, AF-Q8Z6A7-F1) and the mature-range models used
scripts/             analysis and figure scripts (see scripts/README.md)
figures/             report figures regenerated by the scripts
environment/         conda environment exports (see environment/README.md)
```

## Reproducing the tables and figures

From the repository root:

```bash
python3 -I scripts/gene_prevalence.py        # results/genomes/gene_prevalence_unique.csv
python3 -I scripts/make_figures.py           # figures/fig1, fig4, fig6, fig7, fig8
# ranking, classes and pore accessibility (inputs listed in scripts/README.md)
bash scripts/run_ranking_pipeline.sh all
# Figure 5 (needs: npm install 3dmol; pip install playwright pillow matplotlib; playwright install chromium)
python3 -I scripts/render_structures.py node_modules/3dmol/build/3Dmol-min.js
```

## Pipeline

| Step | Tool | Output |
|---|---|---|
| Genome sets (Typhi, Paratyphi A, NTS, confounders) | NCBI RefSeq complete genomes; labels by serovar, not taxon | `data/input/genome_labels.tsv` |
| Gene presence, alignments | DIAMOND, MAFFT | `results/genomes/` |
| Antigen suitability | SignalP 6.0, DeepTMHMM, Protein-Sol (web servers) | mature ranges: HlyE 1-303, YncE 31-353, CdtB 23-269 |
| Structures | 1QOY (*E. coli* HlyE); AlphaFold DB models (v6) for YncE and CdtB | `structures/` |
| Structure checks | ProSA-web, MolProbity (1QOY, after Reduce) | HlyE Z -7.91, 2.00 A, MolProbity 1.23; YncE Z -7.71; CdtB Z -6.83 |
| B-cell epitopes | BepiPred-3.0, DiscoTope-3.0, ElliPro; residues called by >=2 tools | `scripts/consensus.py`, `results/epitopes/consensus_epitopes.csv` |
| Cross-reactivity | DIAMOND and exact k-mer screen vs NTS, confounders, human, *Plasmodium* | `scripts/crossreactivity/` |
| Ranking | `scripts/rank_epitopes_v3.py`: conservation .25, NTS specificity .30, other specificity .20, accessibility .15, prior evidence .10; 1000 weight perturbations at +-10% and +-20% | `results/epitopes/epitope_ranking_v3.csv` |
| Classification | `scripts/classify_segments.py`: Paratyphi A identity to the Typhi segment (>=80% pan-typhoidal, 0% Typhi-selective) | `results/epitopes/epitope_classes.csv` |
| Pore accessibility | Shrake-Rupley (Biopython), 1QOY monomer vs 2WCD chain and pore | `results/epitopes/pore_rsa_segments.csv`, `pore_rsa_residues.csv` |
| West African genomes | NCBI Datasets metadata, DIAMOND/tblastn, SISTR | `results/west_africa/` |

The web-server steps (SignalP, DeepTMHMM, Protein-Sol, BepiPred, DiscoTope, ElliPro, ProSA, MolProbity) were run
manually in October 2026; their raw outputs are summarised in the CSVs above, not stored as HTML or PDF.
The 2WCD pore structure (PDB 2WCD) is a public RCSB entry and is not stored here; download it to rerun the pore step.

## Data provenance and known issues

- Accessions for every genome used are in `data/input/genome_labels.tsv`. Genome FASTA files, proteomes and the large
  NCBI Datasets `.jsonl` summaries are not stored (see `.gitignore`).
- `results/west_africa/west_african_genomes.tsv` lists West African records from the NCBI summaries (strict whole-country
  match on `geo_loc_name`): 280 Nigerian and 119 other West African Typhi records, 3 Paratyphi A, and complete
  *Salmonella* genomes from Nigeria, Mali, Niger and Senegal. An earlier tally recorded 447 West African Typhi records;
  the 399 here come from a stricter country match and the difference has not been resolved.
- Four genomes labelled serovar Typhi (GCF_003717285.1, GCF_003717435.1, GCF_003717515.1, GCF_028747845.1) were downloaded
  into the non-typhoidal folder; the analysis counts them as Typhi. GCF_020714685.1 (organism Typhimurium, serovar field Typhi)
  is not in the presence table.
- `presence_long.tsv` has duplicate rows for six genomes (those four Typhi genomes, and GCF_000750375.1 and GCF_001185215.1
  in Enteritidis). Counted on unique genomes the NTS set is 131, not 133, so NTS hlyE/cdtB prevalence is 7.6%/8.4%
  (`results/genomes/gene_prevalence_unique.csv`), not 7.5%/8.3% as in `gene_level_summary.csv`. The ranking tables still
  carry the earlier NTS and confounder percentages (about 0.1 point lower); the ranking was not recomputed.
- GCF_001628755.1 (IIIb 60:r:z) is *S. enterica* subsp. *diarizonae* by SISTR, filed in the NTS group.
- `results/west_africa/sistr_out.csv` has the local `fasta_filepath` column removed.
- Prior-evidence scores are judgement calls; the no-prior ranking is the primary ranking.
- Only 9 Paratyphi A genomes are available, none from Nigeria. Nigerian Typhi genomes are largely clonal and mostly drafts;
  "not detected" is not "absent".
